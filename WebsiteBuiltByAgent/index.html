Features

Everything you need in your terminal

🤖

Agent Mode

Describe a task and let the agent work. Every file change and shell command is staged for your review before anything is applied.

📋

Plan Mode

Break a goal into steps, review them, select which to execute, and confirm before any changes touch your disk.

❓

Ask Mode

Ask questions about your workspace and save the answers as Markdown files after reviewing the proposed creation.

🌐

Optional Web Access

Enable FireCrawl for web search, crawling, and URL fetching when you need external context in Ask and Plan modes.

🔑

One Key, Any Model

Powered by OpenRouter — connect to any model with a single API key, including free text models.

🎨

Pretty CLI

Interactive prompts with Clack, colorful output with Chalk, and poster-style text with Figlet.

CLI Modes

Choose your workflow

Agent

Autonomous Task Runner

Describe what you want to build or fix. Review staged changes, approve individually or all at once, then cancel if needed.

Plan

Structured Execution

Generate a step-by-step plan for your goal. Select the steps you want to run, confirm, and review staged changes before applying.

Ask

Workspace Q&A

Ask questions about your codebase. Review the model's answer and save it as a Markdown file in your project.

Get Started

Run it locally in seconds

Install Bun, set your OpenRouter key, and launch the assistant in your current working directory.

# 1 Install dependencies
bun install --frozen-lockfile

# 2 Configure environment
cp -n .env.example .env
# Set OPENROUTER_API_KEY and DEFAULT_MODEL in .env

# 3 Start the assistant
bun run start
